# Issue と Pull Request について / Contributing

## 日本語

このリポジトリは、作者が個人で、ボランティアとして開発・管理しています。

- **要望・不具合の報告:** GitHub Issues で受け付けています。
  - 不具合を報告する場合は、次の情報があると助かります。
    - Chrome のバージョン
    - 拡張機能のバージョン
    - 再現手順
    - 期待した動作と実際の動作
  - 対応するかどうかや時期は作者が判断し、対応をお約束するものではありません。
  - 第三者のサイトでの表示結果をもとにした、特定のサイトについての相談には対応できません。
- **Pull Request:** 受け付けていません。届いた場合も、取り込まずにクローズすることがあります。改善の提案は Issue でお知らせください。
- **セキュリティ上の問題:** 公開の Issue に詳細を書くのは避けてください。GitHub の「Report a vulnerability」（Private vulnerability reporting）が有効になっている場合は、そちらからご連絡ください。
- **改変について:** [MIT License](LICENSE) の範囲で、クローン・Fork・改変は自由です。
  - 改変版について、作者は責任を負わず、サポートもしません。
  - 改変版を公開する場合は、別の名前とアイコンを使ってください。

## English

This repository is developed and maintained by a single author as a volunteer project.

- **Feature requests and bug reports** are welcome via GitHub Issues. There is no guarantee that they will be addressed, or when.
- **Pull requests are not accepted.** They may be closed without being merged. Please open an issue instead.
- **Security issues:** please do not post details in a public issue. Use GitHub's private vulnerability reporting if it is enabled.
- **Forks and modifications** are allowed under the [MIT License](LICENSE). Modified versions are not supported, and the author accepts no responsibility for them. Please use a different name and icon when publishing one.
